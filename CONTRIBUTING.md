# Contributing to Clean Code Engineer

Thank you for helping make this skill useful to more developers and AI coding agents.

## Ways to contribute

- Open an [issue](https://github.com/VivatVibe/clean-code-engineer/issues) to report unclear advice, an unsafe suggestion, an installation problem, or an agent compatibility issue.
- Propose original, evidence-based maintainability heuristics and workflows.
- Improve Thai/English setup instructions and cross-platform support.
- Add small, independently written examples or test cases.

## Before making a pull request

1. Fork the repository or create a feature branch.
2. Keep `SKILL.md` focused on concise instructions. Put longer background information in `references/`.
3. Prefer measurable correctness, safety and clarity to arbitrary formatting rules.
4. Don't silently add tools, paid services, network actions, or destructive commands.
5. Run `python3 scripts/validate_skill.py` and `python3 -m unittest discover -s tests -v`.
6. Explain the problem, change, and how it was verified in your PR.

## Copyright and AI contributions

This project is **MIT licensed** for its original material. Do not upload the *Clean Code* PDF, copy substantial sections, reproduce the book's examples, or paste content from other protected sources without permission. Cite references and rewrite ideas in your own original wording.

AI-assisted contributions are welcome, but contributors must review the resulting changes, verify technical claims, and ensure they have the rights to submit the code and text.

## Issues and security

Please open a GitHub Issue for normal bugs, wording concerns, or documentation problems. For a possible security vulnerability, avoid posting credentials or exploit secrets publicly; use private GitHub security reporting if enabled, or request a private contact channel first.

## Conduct

Keep feedback specific, constructive, and respectful. Critique code and ideas, not people.
